# Differentiation playbook

## Decision matrix

| Overlap | User value | Adobe Express fit | Verdict |
|---|---|---|---|
| low | clear | strong | Proceed |
| medium | clear and distinct angle | strong | Differentiate |
| high | identical to existing tools | any | Reconsider |
| any | vague | any | Reconsider |
| any | clear | weak (needs unsupported APIs) | Reconsider |

## Differentiation angles that actually work

- narrower scope: do one job extremely well instead of bundling many features
- specific user persona: target a niche workflow (educator, social marketer, podcaster) rather than "everyone"
- workflow integration: connect a service the existing tools do not connect to
- output quality: produce results that match a higher craft bar than competitors
- speed and clarity: same outcome but with fewer clicks and clearer feedback

## Differentiation angles that usually fail

- "ours but with AI" without a concrete AI-specific user benefit
- "ours but better UI" with no measurable user-facing gain
- "ours but free" — pricing alone is not a product position
- a feature dump that touches the same primary loop as competitors

## How to phrase the verdict

- Proceed: name the user, the trigger, and the outcome in one sentence
- Differentiate: name the closest competitors and the one specific angle that beats them
- Reconsider: explain whether the issue is overlap, value, or feasibility — pick one
