# UI stack guide

## Preferred order

1. Spectrum Web Components
2. swc-react for React repos
3. React Spectrum only when the repo already depends on it or there is a strong reason

## Theme essentials

- import Spectrum typography
- import Express theme definitions
- wrap content with Express theme configuration
