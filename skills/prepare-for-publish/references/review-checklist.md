# Review checklist

## Must-have submission items

- files
- assets
- release notes
- testing information

## Functional review focus

- core feature reliability
- login and logout completeness
- broken links, icons, or event handlers
- browser compatibility across Chrome, Safari, Edge, and Firefox

## UX review focus

- navigation is clear
- background operations show progress
- validation and errors are actionable
